You are a health-insurance appeals expert.  Classify the denial reason in the claim below
into exactly one of the six categories and provide a one-sentence rationale.

## Categories

| Value | Description |
|---|---|
| `medical_necessity` | Payer determined the service was not medically necessary |
| `prior_authorization` | Required pre-authorization was missing or denied |
| `coding_error` | CPT/ICD-10 mismatch, modifier missing, or unbundling issue |
| `out_of_network` | Provider or facility was out of network |
| `not_covered_benefit` | Service is excluded from the plan's covered benefits |
| `administrative` | Missing information, timely filing violation, or other admin reason |

## Output schema

Return **only** a single valid JSON object — no prose, no markdown fences:

```json
{
  "category":  "<one of the six values above>",
  "rationale": "<one sentence explaining the classification>"
}
```

## Rules
- Choose the single most specific category.  If the denial letter mentions multiple reasons
  choose the **primary** reason.
- The rationale must be ≤ 30 words and must reference specific language from the claim.
- Output only the JSON — any additional text will cause a parse error.
